The aim of this project is to explore python fundamentals and data structures with practical examples. The project is kept simple and beginner friendly which could be utilised as a guide to learn python with no prior experience. 

# How to Install Python on  Windows

### Step 1: Download Python
Go to python.org
Click Downloads → Select latest Python version
Download the .exe installer

### Step 2: Run Installer
Double-click the downloaded file
Check the box: "Add Python to PATH"
Click Install Now and wait for installation to complete

### Step 3: Verify Installation
Open Command Prompt and run this command: python --version
You should see something like: Python 3.12.0

# How to Install Python on  Linux 
Run these commands one after another. 
``sudo apt update 
``sudo apt install python3
``python3 --version
After last command you should see a version of python such as 3.12.0

# Fundamentals Topics Covered
    Variables & Data Types – Integers, floats, strings, booleans
    Conditionals – if, elif, else statements
    Loops – for loops, while loops, range()
    Functions – def, parameters, return statements, *args, **kwargs
    Strings – Creation, indexing, slicing, immutability and string methods – upper(), lower(), split(), join(), strip(), find(), replace()
    Operators – Arithmetic, comparison, logical (and, or, not)
    Input/Output – input(), print()
    Lambda Functions – lambda x: x * 2
    Exception Handling – try, except, finally, raise
    File I/O – open(), read(), write(), close()
    Modules & Imports – import, from...import
    OOP (Classes) – Classes, objects, inheritance, methods, init
    Built-in Functions – len(), max(), min(), sum(), enumerate(), zip(), map(), filter()

# Data Structures Covered 
    List – Ordered, mutable, indexed; append(), pop(), insert(), remove(), sort()
    Tuple – Ordered, immutable; faster, hashable
    Dictionary – Key-value pairs; keys(), values(), items(), get(), pop()
    Set – Unordered, unique elements; add(), remove(), union(), intersection()
    String – Immutable sequence; indexing, slicing, methods
    Deque – Double-ended queue (from collections); O(1) append/pop both ends
    Stack – LIFO structure (using list or deque)
    Queue – FIFO structure (using deque or queue module)
